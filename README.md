코에이의 고전 명작 **대항해시대2(한글판, 1993)** 를 브라우저에서 바로 플레이할 수 있게 해주는 웹 래퍼입니다.
설치 없이 PC와 모바일 어디서든 실행되고, 세이브는 브라우저에 자동 저장됩니다.

**[▶ 게임 시작하기 (GitHub Pages)](https://sigco3111.github.io/unchartedwaters2/)**

## 이 저장소는

- 원본 프로젝트: **[wan2land/unchartedwaters2](https://github.com/wan2land/unchartedwaters2)** (원저작자: wan2land)
- 이 저장소는 원본을 **포크(fork)하여 개선을 이어가는 개인 프로젝트**입니다.
- 원본 README는 [README.upstream.md](./README.upstream.md)에 그대로 보존되어 있습니다.

## 저작권 안내 (중요)

- 게임 데이터(`game/` 폴더의 `water2.zip`)는 **코에이(KOEI)의 상용 게임 '대항해시대2' 원본**이며, 저작권은 코에이 및 권리자에게 있습니다.
- 함께 포함된 팬 제작 모드(교정판, 에르네스트, 정화편, 밀란다/살바도르편 등)는 각 제작자(네이버 카페 대항해시대2 커뮤니티)의 저작물입니다.
- 래퍼 코드의 저작권은 원저작자(wan2land)에게 있으며, 원본 저장소에는 별도의 오픈소스 라이선스가 명시되어 있지 않습니다.
- 이 포크는 **비상업적 팬 프로젝트**로, 권리자 또는 원저작자의 삭제 요청이 있으면 저장소와 배포 페이지를 즉시 내립니다.

## 실행 환경

- 인터넷 익스플로러는 지원하지 않습니다. **크롬, 파이어폭스, 사파리 또는 모바일 브라우저**에서 실행하세요.
- 별도 서버가 필요 없는 정적 사이트입니다 (GitHub Pages).

## 사용법

- 공통
  - 게임 내 세이브는 브라우저(IndexedDB)에 저장됩니다. 브라우저를 종료해도 유지됩니다.
  - Dropbox 계정을 연결하면 세이브를 여러 기기에서 동기화할 수 있습니다.
  - 교정판의 첫 메인 메뉴(불러오기·새 게임 선택 화면)는 마우스 클릭에 반응하지 않으므로 방향키와 Enter로 조작하세요.
- 데스크탑 + 풀키보드: 오리지널 키 매핑 그대로 플레이 가능합니다.
- 데스크탑 마우스: 게임 화면을 실제 마우스로 클릭해 조작할 수 있습니다 (v1.0.6). 커서 이동과 클릭이 DOS 마우스 입력으로 전달됩니다.
- 데스크탑 + 텐키리스:
  - 항해 시 방향키를 사용할 수 있습니다.
  - `Q`, `W`, `E`, `R` 키로 메뉴를 활성화할 수 있습니다.
- 모바일:
  - 가상 키패드와 가상 조이스틱으로 진행할 수 있습니다.
  - 상단의 커서 아이콘 버튼으로 **터치 마우스 모드**를 켤 수 있습니다. 화면을 마우스처럼 사용합니다 (탭 = 왼쪽 클릭, 드래그 = 커서 이동). 다시 누르면 조이스틱 모드로 돌아갑니다.

## 기술 스택

- **js-dos 6.22** (DOSBox WASM): 원본 DOS 게임을 브라우저에서 실행
- **Preact + TypeScript + Vite 5 + Tailwind CSS**: 래퍼 UI
- **nipplejs**: 모바일 가상 조이스틱
- **IndexedDB**: 세이브 파일 로컬 저장
- **Dropbox SDK**: 세이브 클라우드 동기화 (선택 기능)

## 이 포크의 변경 사항

### 2단계 - 터치 마우스 모드 (v0.6.0)

- 모바일/태블릿에서 화면 터치를 DOS 마우스 입력으로 전달: 손가락 위치가 마우스 커서, 탭은 왼쪽 클릭, 드래그는 커서 이동
- 상단 툴바의 커서 아이콘으로 조이스틱 모드 ↔ 터치 마우스 모드 전환
- 드래그 후 떼면 클릭되지 않아 의도치 않은 선택 방지 (10px 임계값)
- 탭한 위치에 잠깐 표시가 나타나 클릭 지점을 눈으로 확인 가능

### 1단계 - GitHub Pages 배포 대응 (v0.5.4 기반)

- `vite.config.ts`에 `base: "/unchartedwaters2/"` 적용, GitHub Pages 서브 경로에서 정상 동작하도록 정적 자산 경로 수정
- 저자 전용 도메인용 `CNAME`(water2.dist.be) 제거
- js-dos/게임 zip 로딩 경로를 `import.meta.env.BASE_URL` 기준으로 변경
- GitHub Actions로 자동 빌드·배포 (`.github/workflows/deploy.yml`)
- README 개편 (원본은 README.upstream.md로 보존)

## 3단계: 한국어 가이드 (v0.7.0)

- 시작 화면과 게임 화면 헤더에 '게임 가이드' 버튼 추가
- 가이드 내용: 버전 선택 안내, PC/모바일 조작법(터치 마우스 모드 포함), 세이브/불러오기(로컬·파일·드롭박스), 문제 해결, 저작권 안내

## 4단계: 편의 기능 (v0.8.0)

- 세이브 자동 백업: 게임 내 세이브 시 직전 세이브를 자동으로 백업하고, 메뉴(≡)의 '이전 세이브로 되돌리기'로 복원 가능 (현재 진행은 백업으로 보관)
- 화면 캡처: 헤더의 카메라 버튼으로 현재 게임 화면을 PNG 이미지로 저장

## 5단계: 매크로 녹화/재생 (v1.0.0)

- 메뉴(≡)에서 반복할 조작(키보드·조이스틱 입력, 화면 클릭)을 녹화하고 저장(버전별로 브라우저에 보관)
- '매크로 재생' 시 반복 횟수를 화면에서 선택(1/3/5/10/30회), 재생 중에는 화면 하단의 빨간 '매크로 중지' 버튼으로 즉시 중단 (v1.0.1)
- 한계: 화면 상태(전투 돌입, 폭풍 등)를 감지하지 못해 예상 밖 상황에서는 계속 입력됨. 재생 중 화면 확인 필요

## v1.0.5 마무리

- 제공 범위: 터치 마우스·조이스틱, 입력 매크로, 세이브 백업·복원, 가이드 및 화면 캡처
- 검증되지 않은 자동 항해 버튼과 방향 고정 입력은 제거했습니다. 자동 항해·자동 무역은 제공하지 않습니다.
- DOS에서 탭을 놓치지 않도록 클릭 누름 시간을 100ms로 유지합니다.
- 터치 마우스: 탭은 클릭, 드래그는 커서 이동입니다. 취소된 터치와 여러 손가락 터치는 클릭하지 않으며 모드 전환 시 방향 입력을 해제합니다.
- 세이브 백업은 직전 1개를 보관합니다. 복원 후 새로고침해야 적용됩니다.
- 터치 입력은 사용자 실기기(iPhone)에서 정상 동작을 확인했습니다 (v1.0.6 기준).

## v1.0.6 - PC 마우스 클릭 수정

- 데스크톱 브라우저에서 실제 마우스 클릭이 게임(DOS 캔버스)에 전달되지 않던 문제 수정
  - 터치 입력용 화면 영역이 캔버스를 덮어 마우스 이벤트를 가로막던 문제 해결
  - 모바일용 가상 조이스틱이 데스크톱에서도 생성되어 마우스 입력을 가로채던 문제 해결 (조이스틱은 이제 터치 기기에서만 표시)
- PC에서 마우스 클릭으로 캐릭터 선택 등 화면 조작이 가능함을 실제 PC 브라우저에서 확인
- 아이폰 터치 동작도 사용자 실기기에서 정상 동작 확인
